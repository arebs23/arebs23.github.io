The project explores how a language description can identify an object in a 3D scene and estimate its six-degree-of-freedom pose, which describes its position and orientation.

## Implementation

The public repository contains a pose model built on ScanReason’s 3D grounding code, a PointNet-based pose grounder, pose annotations, and scripts for training and evaluation.
